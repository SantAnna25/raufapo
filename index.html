Como Jogar

Enfrente oito chefes em batalhas de conhecimento. Cada pergunta é um golpe: acerte para ferir o inimigo e sobreviva às respostas erradas.

  • ⚔
    Resposta correta

    O chefe sofre 200 de dano. São necessários cinco acertos para derrotá-lo.

  • ☠
    Resposta errada

    O chefe contra-ataca e você perde vida. Se o HP do herói chegar a zero, é derrota.

  • 🧪
    Poções de cura

    Use uma poção durante a batalha para recuperar vida. Você ganha novas poções ao vencer chefes.

  • 👑
    Progresso

    Derrote um chefe para desbloquear o próximo. Ao vencer todos, o reino estará salvo.

Cada chefe tem um nível de dificuldade. As perguntas ficam mais desafiadoras conforme a jornada avança.
